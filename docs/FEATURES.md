# Feature Matrix

"Implemented" means the feature works in this release. Items under *Not included* are not available.

## Activation
| Feature | Status | Notes |
|---|---|---|
| Supported Websites master gate | Implemented | Only listed and enabled sites run the extension; all others sleep |
| Sleep mode indicators | Implemented | Grey "zzz" badge and popup status |
| Live wake / sleep | Implemented | Open tabs follow list changes immediately, with full clean-up |
| Per-site features | Implemented | Toolbar, selection toolbar, vocabulary, listen, focus, Pomodoro, native reading, reading tracking, auto-scroll, article detection |
| Subdomain and path rules | Implemented | Include subdomains, only-these-paths, never-on-these-paths |
| Test a page | Implemented | Shows Active or Sleeping for any address |

## Reading and capture
| Feature | Status | Notes |
|---|---|---|
| Floating toolbars | Implemented | Main, selection / vocabulary, media, productivity; six layout types |
| Article capture | Implemented | Title, URL, author, image, description, date, tags, word count, reading time |
| Reader Workspace | Implemented | Sanitized structured HTML, table of contents, themes, width / size / line height |
| Smart Audio Reader | Implemented | Synchronized highlighting, sleep timer, bookmarks, notes, shortcuts |
| Highlights, quotes, paragraphs, selections, bookmarks | Implemented | Stored with their source article; See Saved page |
| Link context menu | Implemented | Open in Reader Workspace / Save article from any link |
| Focus, ad hiding, native reading | Implemented | Ad hiding is best-effort |
| Pomodoro and 80/20 | Implemented | Configurable durations |

## Library and data
| Feature | Status | Notes |
|---|---|---|
| Vocabulary | Implemented | Categories, examples, tags, mastered, revision quiz, Markdown / CSV / JSON export |
| Translation | Implemented | Public MyMemory endpoint; selected text only, on request |
| My Reading Library | Implemented | Websites, newspapers, profiles, categories, tags, logos, Details view |
| SEO and ranking | Implemented | 14-check score, Tranco rank, PageSpeed / Lighthouse, per-article audit |
| Article Library | Implemented | Search, refresh, fetch, import / export, details, edit, remove |
| Medium / Freedium | Implemented | Mirror hand-off, complete-article extraction, adapter packages |
| Exports | Implemented | Markdown, TXT, HTML, JSON, vocabulary CSV, full backup, database ZIP |
| GitHub Data Sync | Preparation | Difference ZIP and manual folder write; no automatic push / pull |
| Notifications | Implemented | Toasts with position, duration and per-event toggles |

## Not included
- AI summaries, Q&A and flashcards (settings are stored; no requests are sent).
- True PDF / DOCX generation, semantic search, knowledge graph, cloud sync.
- Adaptive spaced repetition (basic review scheduling only).
- Official Medium account or quota status.
