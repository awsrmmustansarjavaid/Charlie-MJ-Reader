## Documentation conventions

- The documentation describes the implementation represented by this release, not a roadmap promise.
- “Implemented” means available in the current build; settings or preparation tooling are identified separately.
- Browser, operating-system, website and third-party service behavior can affect results.
- For privacy-sensitive workflows, review [PRIVACY.md](PRIVACY.md) before enabling a website.
