# Brand assets

- `logo.svg`: editable vector master logo.
- `icons/icon.svg`: source artwork for the extension icons; `icons/icon16.png`, `icon32.png`, `icon48.png`, `icon128.png` are the sizes Chrome uses.
- `thumbnail.png`: 1536×1024 project overview image.
- `thumbnail-instagram-story.png`: 1080×1920 (9:16) Instagram Story / Reels cover. Key content stays inside the safe area (about 250 px from the top and 340 px from the bottom).

For Chrome Web Store publishing, export the SVG master to 16, 32, 48 and 128 px PNG files.
