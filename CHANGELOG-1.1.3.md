# Version 1.1.3 — Productivity and Library additions

- Added a dedicated See Saved page that groups saved paragraphs/lines, words, quotes, highlights, notes, bookmarks and selections.
- Renamed the sidebar Paragraphs entry to Saved Paragraphs.
- Removed the duplicate “Note at position” action from the audio control deck; the right-side Productivity Toolbar retains “Add note at position”.
- Added configurable button-click feedback notifications and unified reader control/search backgrounds.
- Added saved-library search suggestions using browser autocomplete.
- Added local folder selection in Data Sync and a manual JSON backup writer for the selected folder. Chrome folder permission is session-scoped; reselect the folder after reopening Settings.
- Added consistent hover, active, and disabled button styling.
