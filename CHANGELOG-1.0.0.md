# Charlie MJ Reader v1.0.0

## Unified Reading Workspace
- Reader Sidebar renamed to Reader Workspace.
- Media Reader renamed to Productivity Reader.
- Read Yourself opens directly in Productivity Reader.
- Listen opens Productivity Reader and starts speech automatically.
- Article titles/thumbnails open the Productivity Reader.
- Article Library linked to the same Saved Articles records used by My Reading Library.
- Added Article Library search, refresh, import/export/download, details, edit and remove controls.
- Added right-side Reader Capture tools for Vocabulary, Quotes, Paragraphs and Custom Selections.
- Added bottom-right toast notifications with configurable position, duration and event settings.
- Added active/pressed/loading button states.
- Added parent-page selection capture and reading-position tracking.
- Added parent-page current reading focus highlighting and native automatic reading controls.
- Added shared Reading Engine data model for positions and saved selections.
- Extension package version is 1.0.0.
